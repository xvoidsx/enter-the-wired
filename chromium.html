NAVI // CHROMIUM

the browser is part of the OS.

On navi, the browser isn't just an app — it's an application runtime, a policy surface, a visual layer, and eventually a platform we intend to shape ourselves. This page documents how Chromium integrates with navi today, what we're pushing upstream, and where accela, our future Chromium fork, fits in.

SHIPPED

the webapp runtime

A navi webapp isn't a bookmark. It's an installed desktop entry with its own icon, its own window, and the same launcher visibility as a native application. 72 launchers ship today, each one a Chromium --app window with --force-dark-mode.

The public CLI is navi-webapp — install, uninstall, list, doctor. First-party front doors (navi radio, neighborli, glyyph, the naviApps storefront) show the strategy: the distro's own services arrive as web technology without feeling bolted on.

Local-first engineering shaped the design. The naviApps storefront once read its catalog with fetch() — which breaks under file:// when a browser process is already running. The fix was architectural: apps.json stays the source of truth, but build-catalog.sh emits an inlined catalog.js. No hidden server, no launch-flag roulette.

  • App mode matters: independent compositor window, rofi launch by name and icon, task switching treats it as an application.
  • Deterministic dark mode: a wrapper puts --force-dark-mode first, so sway gets a dark browser even when the desktop portal isn't answering — and an explicit --force-light-mode can still override it. A curated default, not a lock.

SHIPPED

managed policy

navi uses Chromium's managed policy layer to install a small, explicit baseline: the nightshadeNeon theme, uBlock Origin Lite, and Proton Pass — pinned stable extension IDs, force-installed, stored as JSON under /etc/chromium/policies/managed/.

What it buys: coherence (a new profile still looks and behaves like navi), privacy by default (blocking is present before anyone shops for an extension), and supportability (bug reports start from a known baseline).

What it obligates: keep the list small — a non-removable default carries more responsibility than a recommendation. Pin stable channels only. State ownership honestly: uBOL is upstream's, Proton Pass is Proton's. Coherence is useful only when the user can understand what's being enforced and why.

THE LINEUP

one runtime contract, several browsers

navi can be opinionated about the integration layer without pretending there's one correct browser for everyone.

  • Chromium (default today). Debian's Chromium is the known baseline — the wrapper, launcher overrides, app windows, and policy are designed around it.
  • Helium (dogfooding). imput's open-source Chromium fork, based on ungoogled-chromium. Raven runs it as his daily driver while navi evaluates it as the likely base for accela — watching security-update lag across releases and keeping the divergence list short.
  • Microsoft Edge (optional). Being evaluated as a user choice, not a default. Its sleeping-tab controls are unusually granular — a real story on low-power machines. Its telemetry model doesn't fit navi's zero-telemetry direction, so that tradeoff is stated plainly rather than buried in fine print.
  • More via navi-extras. The post-install menu offers user-driven browser additions; installer scripts live under scripts/installers/ and are never run by the main installer — one optional browser failure must never endanger the OS install.

Planned: a settings TUI to choose which installed Chromium-family browser the webapps launch through. Scope stays Chromium-based — app mode and managed policy are the contract navi can support consistently.

UPSTREAM CITIZENSHIP

fix upstream, don't just patch around

navi's first response to a browser bug shouldn't always be a distro-only patch. When the failure belongs upstream, the useful work is evidence, a clear report, and verification when a fix lands.

Our public tracker (docs/edge-linux-feedback.md in the navi repo) currently carries two Edge-on-Linux issues: EDGE-LINUX-001, the Copilot toolbar button not functioning on Linux, and EDGE-LINUX-002, the "use system title bar" toggle doing nothing at all. On 23 September 2026, Raven submitted both to the Edge Linux team through Edge's feedback system — screenshot, screen recording, detailed write-up — identifying himself as a navi maintainer who wants Edge to be a reliable distro option.

A distro maintainer lobbying Microsoft for better Linux support is unusual leverage. Spend it deliberately: reproducible behavior, visual evidence, one public status page, no inflated claims. A vendor response is not the same as a verified fix — we'll test on real navi hardware before closing anything.

DOGFOODING

blackice

blackice is xvoidsx's Manifest V3 ad and tracker blocker — a fork of uBlock Origin Lite with a nightshadeNeon interface. Raymond Hill's copyright and the uBlock contributors' notices stay intact; xvoidsx adds its copyright only to its own interface, branding, defaults, and genuine curated-list work.

The transition is staged on purpose: uBlock Origin Lite is still the force-installed policy blocker today. blackice is dogfooding now, and only after it earns the job does the policy ID change. Later, a native adblock-rust component inside accela becomes the deeper engine — one brand, two engines.

Boundaries that protect credibility: never present it as an official uBlock project, never dogfood it beside uBO or uBOL, never show fake statistics or placeholder lists.

THE HORIZON

accela

accela is xvoidsx's planned Chromium-based browser — where the browser becomes an owned interface to the wired. Forking raw ungoogled-chromium would maximize control and release-engineering burden simultaneously; Helium is the practical starting point, with a clean, legible patch stack and an escape hatch back to plain UGC if its direction or cadence stops fitting.

  • Smallweb built in — gemini and other smallweb paths as first-class navigation.
  • Zero telemetry — privacy as an architecture constraint, not a setting.
  • Hey Lain — local and cloud agent support replacing the generic "AI Mode" story.
  • Private search — with a smallweb-scoped index as the long-term wedge.
  • Native bangs — !radio, !nl, !apps, !wired: the address bar as a map of navi's front doors.

"Wallpaper is the theme": Chromium's native color extraction can tint the whole browser chrome from a new-tab-page wallpaper. In testing, navi gifpapers each produced coherent palettes — pulsegrid is the leading default, jellyfish the showcase alternative. The selected gifpaper becomes the browser's visual source of truth.

Sequencing matters: accela comes after the desktop navi launch, navidroid, and eiri work. Firefox remains on the roadmap as a cross-engine hedge; Safari is explicitly out of scope.
