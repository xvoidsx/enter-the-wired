NOW // STABLE

navi 1.6 “mika”

The current stable release. A dependable Debian base, the wired tiling desktop (Wayland-first, X11 fallback), open agent tools baked in from first boot, and the smallweb application layer — now with its own update channel. navi-update pulls new releases and redeploys around your customizations; navi-wired-restore keeps the desktop layer honest, and navi-wired-adopt takes a release's new desktop defaults wholesale when you want them.

  • self-updating — navi-update + navi-wired-restore + navi-wired-adopt, waybar mods that always float (update indicator, notification bell)
  • wired desktop — sway + i3, waybar, rofi, nightshadeNeon everywhere
  • the cohesion update — xvoidsx’s own nightshadeNeon GTK theme, Moka icons, one design language across terminal, bar, launcher and notifications
  • agent-native — ollama, opencode, omp, goose, herdr, and navi-Q on Alt+A
  • webapp layer — naviApps store, navi radio, neighborli, glyyph, Dropbox
  • permacomputing — validated on a 2015 Acer Cloudbook; legacy BIOS + UEFI

ROLLING // NAVI 2 // EIRI

navi 2 “eiri” — the coherence release

Coherence through ownership. One nightshadeNeon design language flowing through every layer xvoidsx builds — the same tokens and interaction grammar in terminal UIs, GTK apps, and the web. Our own stack, from the bottom to the top.

  • navi mods — waybar-driven clickable modules (networks, calendar, reminders, volume, bluetooth) launching small floating TUIs
  • nightshadeNeon as a system — bubbletea/lipgloss TUIs, a GTK3 theme, and web, all speaking one visual language
  • Hey Lain! — a local voice assistant (faster-whisper + piper-tts, no cloud) that can operate the desktop
  • enhance, don't replace — mods sharpen the daily surface without taking Linux away; choice is preserved

Eiri rolls as a real channel now: the eiri branch moves frequently, navi-update --channel eiri switches a mika machine onto it without re-installing, and bench ISOs are cut from the branch for fresh installs. It moves fast and occasionally breaks — mika stays stable underneath it.
