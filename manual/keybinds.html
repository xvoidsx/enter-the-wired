Here is a reference guide for the keybindings used in wired, our tiling window management setup in navi.

Please note that on most keyboards, the Super key is the Windows key, or the Command key on Apple keyboards.

Agents

  • Alt+A - pop up navi-Q with an agent ready to help.
  • Alt+Shift+A - pop up a navi-Q terminal.
  • Alt+V - toggle Hey Lain, the voice assistant. Tap to start listening, tap again to stop and hear her reply.
  • Scroll Lock (hold) - Voxtype dictation. Hold to record, release and your words are typed at the cursor. Needs Voxtype installed; runs the Moonshine Base engine, light enough for old hardware.
  • Super+Ctrl+H - opens herdr, the agent workspace manager, in a terminal.

Workspaces

  • Super+1 through Super+0 - move to workspaces 1 through 10.

Opening Applications

  • Super+Enter - opens a terminal window.
  • Super+Tab - opens the "Nightshade Menu" to launch apps.
  • Super+D - opens the "Nightshade Command Bar" to run commands.
  • Super+Shift+A - opens the "Nightshade App List", another way to launch apps.
  • Alt+B - opens Firefox.
  • Alt+Shift+B - opens your default browser (Brave, unless you've picked another with navi-browser).
  • Alt+E - opens remoji, the emoji picker.
  • Alt+S - opens a vim scratchpad for quick notes (saved to a dated file in /tmp).
  • Super+Shift+F - opens your file manager.
  • Alt+H - opens htop to view system resource usage.
  • Alt+C - opens calcurse, a calendar, todo list, and appointment manager.
  • Super+C - opens gsimplecal, a small GTK calendar.

Window Management

  • Super+Shift+Q - closes the currently focused window.
  • Super+Shift+Number Keys - send the currently focused window to a chosen workspace.
  • Super+F - places the currently focused window in fullscreen mode (use it again to exit fullscreen mode).
  • Super+Shift+Space - floats the currently focused window (use it again to re-tile the window).
  • Super+W - switches your tiled windows to tabbed mode.
  • Super+S - switches your tiled windows to stacked mode.
  • Super+E - toggles the split orientation (horizontal/vertical) of the focused container.
  • Super+Space - switches focus between tiled and floating windows.
  • Alt+Tab - opens the thumbnail window switcher; press it again to advance to the next window.
  • Alt+Shift+Tab - same switcher, but moves to the previous window.
  • Super+A - focus the parent container of the focused window.
  • Super+R - enter resize mode to change window size with arrow keys or vim keys (j/k/l/;) (use it again to exit resize mode).
  • Super+Shift+S - make the focused window sticky, so it follows you between workspaces.
  • Super+Shift+Arrow Keys - swap the placement of windows on the grid (Super+Shift+J/K/L/; does the same, vim-style).
  • Super+Arrow Keys - switch focus between open windows (Super+J/K/L/; does the same, vim-style).
  • Super+H - tile the next window horizontally.
  • Super+V - tile the next window vertically.
  • Super+G - enable window gaps (applies immediately).
  • Super+Shift+G - disable window gaps (applies immediately).

Appearance

  • Alt+T - open the theme picker and switch the waybar theme.

Audio

  • Volume Up / Volume Down - raise or lower the volume in 10% steps (dedicated media keys on most keyboards).
  • Mute - mute or unmute the default audio output.

Any volume change pops up a small meter at the bottom-center of the screen — no matter what changed it: the media keys, scrolling on the waybar volume module, or the navi-audio panel module.

System Operations

  • Super+Shift+N - replay the single most recent notification.
  • Super+P - navishot: pick a screenshot mode - a selected area, a single window, or the entire screen (screenshots are saved at $HOME/Pictures/Screenshots and copied to the clipboard).
  • Super+Shift+P - quick-snag: skip the menu and screenshot a selected area immediately (same save location and clipboard behavior).
  • Super+Shift+Z - lock your screen, requiring your password to return to the desktop.
  • Super+Shift+R - reload the sway configuration in place.
  • Super+Shift+E - log out of wired.
  • Super+Shift+H - launch the navi help manual to learn how the system works.

Note that if you wish to change any of these keybindings, or add your own, you can edit the configuration file location at $HOME/.config/sway/config and make any changes you wish!
