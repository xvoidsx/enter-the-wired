XVOIDSX // UPSTREAM

the work we send back.

navi stands on other people's work — Chromium, uBlock Origin Lite, matui, and more. This page is the record of what we've sent back the other way: bug reports, fixes, and honest forks. Building in the open means contributing in the open.

how we do upstream work

Reproducible reports, visual evidence, one public status page, no inflated claims. A private patch shifts maintenance onto navi and hides the problem from everyone else; an upstream repair improves things for every distribution. And when a fix lands, we verify it on navi hardware — a vendor response is not the same as a verified fix.

blackice on the Edge Add-ons store

live

blackice is live on the Microsoft Edge Add-ons store — file their bugs, ship their users our work. Edge for Android is next: no sideloading there, so the store listing is the only road to phones. (The nightshadeNeon theme can't follow — Edge's Partner Center rejects theme submissions, so Edge users get it from the Chrome Web Store listing instead.)

yandex browser

Upstream citizenship doesn't check passports. Good tech is good tech, wherever it's from — and a bug report is a bug report.

--app mode renders browser chrome

active

Launched with --app, Yandex Browser should open a chromeless app window — instead it keeps the address bar. No tabs, but the address bar alone defeats the point of app mode. Reported 16 October 2026. Still open, awaiting response.

matui → cyberia

cyberia is xvoidsx's fork of pkulak's matui, the Rust TUI Matrix client. The fork outgrew its origins — but the improvements go back.

clipboard image paste

planned

Paste whatever image is on the clipboard straight into the upload popup — wl-paste on Wayland, xclip on X11, no file picker. Shipped in cyberia; a PR upstream to pkulak/matui is planned.

honest forks

Not every relationship is a contribution. Some are just standing on shoulders without pretending otherwise.

uBlock Origin Lite → blackice

honest fork

blackice is xvoidsx's Manifest V3 ad and tracker blocker, forked from Raymond Hill's uBlock Origin Lite. His copyright stays intact; xvoidsx's is added only to its own interface, branding, and defaults. It is never presented as an official uBlock project — because it isn't, and pretending would cost the credibility the real work earns.

agent-driven Chromium auditing

dreaming

Today the chromium page says we don't audit Chromium ourselves — we ride the update cadence. The dream is a sibling-Lain fleet doing targeted auditing: triaging fuzzer crashes, reviewing patches for the bug classes the hardened allocators haven't killed yet, watching the security feed. Nobody audits all of Chromium. But a small team in the woods with agents can punch above its weight — that's the whole xvoidsx story.
