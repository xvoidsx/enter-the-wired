NAVI // LABS

tuned, not just installed.

navi runs on just about anything — that's the perma-computing promise. But on lab machines it doesn't just run. We get the hardware, we run the full matrix — wifi, suspend, battery, display, keys, firmware — and we tune until the machine feels like it was made for navi. Then we publish the notes, so you can see exactly what we did and why.

GET THE MACHINE

how the lab works

  • We get the machine. Bought, borrowed, or sent by a manufacturer. Lab machines stay on the bench and get re-tested every release — no review units that go back in a padded envelope.
  • We run the matrix. Suspend/resume, wifi chipsets, function keys, display quirks, battery behavior, firmware blobs. Everything navi touches on real hardware, measured on that hardware.
  • We publish the notes. Every tuning decision lands in the machine's lab card — kernel params, firmware, config deltas. If we can't explain a change, it doesn't ship.

FRIENDS OF NAVI

no friends yet — the tier is open.

We don't do “sponsors” and “partners” here — we have friends. A friend of navi supplies something we can't buy: hardware to tune on, inference to test agents against, infrastructure to ship ISOs from. In return they get our best work, published as code, with their name on it.

  • hardware friends — machines on the bench, tuned until they feel made for navi
  • inference friends — models and API access for the agent center
  • infra friends — the pipes that get navi to you

What friendship never means: influence over the roadmap. Friends get our thanks and our best work — never control.

The empty tier is deliberate. It fills when the relationship is real.

FOR MANUFACTURERS

make hardware that respects its owner?

We'd rather tune navi for ten machines deeply than ship a generic image for a thousand. If you build repairable, open, well-documented hardware — the kind of machine someone keeps for a decade — we want it in the lab.

What working with us looks like: you send hardware and give us an engineer to talk to. We do the tuning, publish the notes, and make your machine the best place to run navi. Small team, short loop, no committees. You'll talk to the people who actually build the OS.
